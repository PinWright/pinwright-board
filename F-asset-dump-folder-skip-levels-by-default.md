# asset.dump_folder skips UWorld assets by default with includeLevels opt-in

Levels (`UWorld` / `.umap`) are by far the slowest assets to dump — loading a level pulls its actors, sublevels, and data layers, and a single map can take seconds. Folder sweeps that target UI / Blueprints / materials never need that work. Until now there was no way to skip levels and the dump always included them, which made `asset.dump_folder` impractically slow on any folder that crossed `Maps/`.

**New parameter:** `includeLevels` (boolean, default `false`). When false, `UWorld` assets are filtered out of the pending list right after the asset registry query. When true, the legacy include-everything behavior is restored.

**Default change:** existing callers that omit the parameter now silently get the new (faster, level-free) behavior. The dump output is a developer cache that is re-runnable on demand, so the breakage cost is one extra parameter for the rare caller that wanted levels.

**Files:**
- `Source/EditorAutomationRpcGateway/Private/Handlers/Asset/AssetDumpHandler.h` — added trailing `bool bIncludeLevels = false` to `StartAsyncFolderDump`.
- `Source/EditorAutomationRpcGateway/Private/Handlers/Asset/AssetDumpHandler.cpp` — same signature change, post-query filter in `ShouldSkipFolderDumpAsset` rejecting (a) `Data.AssetClassPath == World` and (b) any row with `(Data.PackageFlags & PKG_ContainsMap) != 0` when the flag is false. The PackageFlags clause is what catches non-World rows (`MapBuildDataRegistry` etc.) that share the level's package and would otherwise queue it via `Data.PackageName`. New `RPC_PARAM_DEF("includeLevels", "boolean", ..., "false")` plus the matching `Ctx.GetBool` read in the handler body.
- `Source/EditorAutomationRpcGatewayTests/Private/Utility/TestAssetDumpHandler.cpp` — `FAssetDumpHandlerAsyncFolderDumpLevelsExcludedByDefaultTest` covering the default-exclude and opt-in paths against `/Engine/Maps`; `FAssetDumpFolderSkipsExternalActorStorageTest` extended with synthetic `MapBuildDataRegistry` FAssetData (one with `PKG_ContainsMap` — must be skipped by default; one without — must not be skipped).
