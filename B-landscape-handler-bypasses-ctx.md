# Multiple Handlers Bypass FHandlerContext in Async Lambdas

Five handler files reach past `FHandlerContext` and call the subsystem's response APIs directly from async lambdas. Every other handler routes through `Ctx.SendSuccess` / `Ctx.SendError`, keeping the request-tracing path (response-capture interception, text formatters, test fixtures) intact.

Affected handlers:
- `Handlers/Environment/LandscapeHandler.cpp` (21 direct calls in AsyncTask lambdas)
- `Handlers/Asset/AssetManageHandler.cpp` (direct calls in AsyncTask lambdas)
- `Handlers/Asset/AssetMetadataHandler.cpp` (direct calls in AsyncTask lambdas)
- `Handlers/Asset/AssetWorkflowHandler.cpp` (direct calls in AsyncTask lambdas)
- `Handlers/Blueprint/BlueprintCreationHandler.cpp` (direct calls in AsyncTask lambdas)

## Why it matters

`FHandlerContext::SendError` and `SendSuccess` do more than forward to the subsystem — they hit `FResponseCapture` when a capture pointer is wired (test fixtures via `MakeTestContextWithCapture`, text formatters in dispatcher line 352-358). Async lambdas that call subsystem APIs directly skip that branch entirely:

- Test fixtures that drive these RPCs through `MakeTestContextWithCapture` cannot observe async responses
- Text formatters registered for handler methods are silently bypassed for async completions
- Response enrichment (trace/log additions tied to context) won't apply to async responses
- Inconsistent observability path between sync and async completions

## Fix approach

Add `FAsyncResponseToken` — a `TSharedRef`-friendly handle holding `RequestId`, `Method`, `TWeakObjectPtr<UEditorAutomationRpcGatewaySubsystem>`, and `FResponseCapture*`. The token's `SendError` / `SendSuccess` route through the same code path as the synchronous helpers, respect captures, and can be safely captured by value in async lambdas.

1. **Add FAsyncResponseToken to HandlerContext.h/cpp** — shareable token with SendError/SendSuccess that mirrors Ctx behavior
2. **Update FHandlerContext** — add `MakeAsyncToken()` factory
3. **Replace direct subsystem calls in 5 handlers** — capture token instead of RequestId, use token's send helpers

This matches UE async patterns (shared handles for async work) and enables both subsystem transport and test fixtures to observe responses consistently.
