# `property.list` auto-resolves Blueprint assets to CDO

`property.list` and `property.get` now auto-resolve Blueprint asset paths to their CDO. Passing `/Game/Foo/BP_MyBlueprint` returns configured CDO properties (Actions, DefaultPawnData, etc.) instead of UBlueprint internals. No need to construct `Default__ClassName_C` inner-object paths.

**Fix:** `ResolveObjectForProperty()` in `UtilityPropertyHandler.cpp` checks if the resolved object `IsA<UBlueprint>()` and redirects to `GeneratedClass->GetDefaultObject()`.

**Gap:** The redirect (line 119-125) only covers the SHORT asset path resolving to a `UBlueprint`. The GENERATED-CLASS object path with the `_C` suffix (`/App/.../W_Foo.W_Foo_C`) resolves via `FindObject` to the `UClass`/`UBlueprintGeneratedClass`, which is not a `UBlueprint`, so the redirect is skipped and the class object is returned. Member-variable lookup then fails on the class metatype → `PROPERTY_NOT_FOUND`. Fix: add a mirror branch redirecting a resolved `UClass`/`UBlueprintGeneratedClass` to `Cls->GetDefaultObject()` (same single fix site).
