# Internal capped supervisor, editor_run_tests and editor_build

`scripts/Run-Capped.ps1`, `scripts/Run-SuiteCapped.ps1` and `scripts/CappedJob.ps1` are
Windows-only, block their caller for the whole run, and cannot carry a launch reason through the
proxy. `editor_prepare_tests` only returned an argv the caller had to launch and supervise itself.
User decision: fold the scripts into Python (stdlib, bundled interpreter, Windows and Linux),
always detached so a run survives the proxy and the MCP client, and replace `editor_prepare_tests`
with `editor_run_tests` (blocks only until the first test starts) plus `editor_test_status`
(non-blocking, keyed by the run's log).
