# MCP widget edits can save un-loadable Widget Blueprints with corrupt panel slots

## Symptom

MCP widget authoring can leave a saved `UWidgetBlueprint` with a corrupt widget tree: a `UPanelWidget` keeps a `UPanelSlot` whose `Content` is null, whose `Parent` points at the wrong panel, or whose child widget no longer points back to that slot. On cold load UE reaches `UPanelWidget::ConnectEditorData()` and crashes while repairing editor data for that slot.

This is the current active vector for this ticket. Older history below covers prior Blueprint-graph and CreateDelegate vectors, but this reformulation scopes the open work to widget-tree panel-slot corruption.

## Root cause

`widget.remove_widget` removes the requested live widget from the `WidgetTree`, then handles graph cleanup. It did not compact stale panel slots that were already present from earlier failed widget edits or rollback paths, and it did not report whether any panel slots were cleaned.

The shared integrity gate also only described and checked Blueprint graph/class-table state. For `UWidgetBlueprint` assets, it did not walk the widget tree and therefore could not block a save containing a corrupt `UPanelWidget::Slots` entry.

## Fix

- Add `WidgetAuthoringHelpers::CompactInvalidPanelSlots(UWidgetBlueprint*, UWidget*)`.
- Call it from `widget.remove_widget` immediately after `WidgetTree->RemoveWidget(TargetWidget)`.
- Return `compactedPanelSlots` in the `widget.remove_widget` response.
- Extend `ValidateBlueprintGraphIntegrity` for `UWidgetBlueprint` assets so each panel slot must be non-null, have non-null `Content`, have `Parent == Panel`, and have `Content->Slot == Slot`.
- Report widget-tree failures as `NodeKind="UPanelSlot"` and `GraphName="WidgetTree"`.
- Update compile/BPIR integrity wording so it says "integrity failure(s)" instead of implying every failure is a stale graph reference.

## Regression tests

- `FWidgetRemoveCompactsInvalidPanelSlotsTest`: plants a null-content panel slot, invokes production `widget.remove_widget`, asserts `compactedPanelSlots >= 1`, and asserts every remaining panel slot has valid content, parent, and back-reference.
- `FWidgetTreeIntegrityDetectsInvalidPanelSlotTest`: plants a null-content panel slot and calls production `ValidateBlueprintGraphIntegrity`, expecting a `UPanelSlot` / `WidgetTree` integrity failure.

## Remaining related vectors

`widget.set` rollback slot cleanup and `blueprint.graph.find_orphaned_nodes` dirty-bit behavior remain separate follow-up vectors recorded in history. They are not implemented by this ticket update.

- **Additional corruption vectors suspected (not yet proven, but consistent with this session's evidence):**
